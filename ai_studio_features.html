🤖 Build an Android app
네이티브 안드로이드 앱을 Kotlin + Android SDK 기반으로 생성합니다. Preview에 에뮬레이터가 뜨며, 한글 입력 제약이 생길 수 있으므로 웹앱 실습 시에는 주의가 필요합니다.
Android / Kotlin
📁 Google Drive
구글 드라이브와 연동하여 파일 읽기/쓰기/검색 기능을 앱에 통합합니다. 사용자의 드라이브에서 문서를 가져오거나 결과물을 저장할 수 있습니다.
파일 관리
📊 Google Sheets
구글 스프레드시트를 간이 데이터베이스처럼 활용합니다. 시트에서 데이터를 읽어오거나, 앱에서 입력한 데이터를 시트에 기록할 수 있습니다.
데이터 저장/조회
📧 Gmail
Gmail API와 연동하여 이메일 발송, 읽기, 검색 등의 기능을 앱에 탑재합니다. 자동 알림 메일이나 보고서 발송 등에 활용 가능합니다.
이메일
📅 Google Calendar
구글 캘린더와 연동하여 일정 조회/추가/수정 기능을 앱에 넣습니다. 스케줄 관리 앱이나 예약 시스템에 활용할 수 있습니다.
일정 관리
📝 Google Docs
구글 문서를 읽거나 작성/편집하는 기능을 앱에 연결합니다. 보고서 자동 생성이나 문서 요약 등에 활용 가능합니다.
문서 편집
📽️ Google Slides
구글 슬라이드(프레젠테이션)를 생성하거나 편집하는 기능을 연동합니다. AI가 내용을 기반으로 발표 자료를 자동 구성할 수 있습니다.
프레젠테이션
☑️ Google Tasks
구글 Tasks(할 일 관리)와 연동하여 작업 생성/완료/목록 관리 기능을 앱에 넣습니다. To-Do 리스트 연동에 유용합니다.
할 일 관리
💬 Google Chat
구글 채팅 메시지를 보내거나 읽는 기능을 앱에 연결합니다. 팀 알림이나 자동 메시지 발송 등에 활용할 수 있습니다.
메시징
📋 Google Forms
구글 설문지(폼)를 생성하거나 응답을 수집하는 기능을 연동합니다. 설문 자동 생성이나 응답 분석에 활용 가능합니다.
설문/양식
💡 Google Keep
구글 킵(메모앱)과 연동하여 메모 생성/검색/관리 기능을 탑재합니다. 빠른 메모 저장이나 아이디어 정리에 활용할 수 있습니다.
메모
🎥 Google Meet
구글 미트 화상회의 링크 생성이나 회의 관련 기능을 연동합니다. 자동 회의 스케줄링 등에 활용 가능합니다.
화상회의
👥 Contacts
구글 연락처에서 연락처를 읽거나 관리하는 기능을 앱에 통합합니다. 연락처 검색이나 자동 그룹 분류에 활용할 수 있습니다.

데이터 & 검색 소스

3개
🔎 Use Google Search data
앱이 구글 검색(Grounding with Google Search)을 활용하여 실시간 웹 정보를 가져와 답변에 반영합니다. 최신 뉴스, 날씨, 가격 정보 등을 앱에서 직접 보여줄 수 있습니다.
실시간 검색
📍 Use Google Maps data
구글 맵스 데이터를 연동하여 지도 표시, 장소 검색, 경로 안내, 주변 맛집/시설 정보 등의 기능을 앱에 넣습니다.
지도/위치
🔥 Add database and auth
Firebase 등의 클라우드 데이터베이스와 사용자 인증(로그인/회원가입) 기능을 앱에 추가합니다. 여러 사용자가 데이터를 공유하는 앱을 만들 수 있습니다.
DB / 인증
🎨

미디어 생성 & 처리 (멀티모달)

6개
🔊 Convert text to speech
텍스트를 자연스러운 음성(TTS)으로 변환하는 기능을 앱에 추가합니다. 읽어주기 기능이나 오디오 콘텐츠 생성에 활용할 수 있습니다.
TTS / 음성 합성
🎵 Generate music
AI를 활용하여 음악을 생성하는 기능을 앱에 탑재합니다. 배경 음악, 효과음, 멜로디 등을 텍스트 설명만으로 만들 수 있습니다.
AI 음악 생성
🖼️ Create & edit images
Imagen 등을 활용하여 이미지를 생성하거나 기존 이미지를 편집하는 기능을 앱에 넣습니다. 썸네일, 배너, 일러스트 제작에 유용합니다.
이미지 생성/편집
🖼️ Generate high-quality images
더 높은 품질과 해상도의 이미지를 생성하는 고급 모드(Imagen 3 등)를 연동합니다. 인쇄용이나 전문 디자인 용도에 적합합니다.
고품질 이미지
🎞️ Animate images into video
정적 이미지를 입력하면 AI가 이를 움직이는 동영상으로 변환(애니메이션화)합니다. 사진에 생동감을 불어넣을 수 있습니다.
이미지 → 영상
🎬 Generate video from text
텍스트 설명만으로 AI가 비디오 영상을 생성합니다 (Veo 모델 등). 짧은 클립, 프로모션 영상 등을 자동으로 만들 수 있습니다.
텍스트 → 영상

AI 고급 설정 & 분석

8개
🎙️ Add voice conversations
앱에 음성 대화(Voice Chat) 기능을 추가합니다. 사용자가 마이크로 말하면 AI가 음성으로 응답하는 양방향 대화가 가능합니다.
음성 대화
✨ Add Gemini intelligence
앱 내에 Gemini 모델의 AI 추론/대화 기능을 직접 내장합니다. 텍스트 요약, 질문 응답, 데이터 분석 등 지능형 기능을 추가할 수 있습니다.
AI 추론 내장
💬 Add a Gemini chatbot
앱에 Gemini 기반 대화형 챗봇 인터페이스를 바로 탑재합니다. 고객 상담, FAQ 자동 응답 등에 즉시 활용 가능합니다.
챗봇
📐 Control image aspect ratios
이미지 생성 시 가로/세로 비율(1:1, 4:3, 16:9, 9:16 등)을 세밀하게 제어하는 설정을 추가합니다. SNS별 최적 사이즈에 맞출 수 있습니다.
이미지 비율
🔍 Analyze images
업로드한 이미지를 AI가 분석합니다. 내용 인식(사물/인물), OCR(글자 추출), 장면 설명 등의 기능을 앱에 넣을 수 있습니다.
이미지 분석
⚡ Add low-latency responses
응답 지연을 줄이는 저지연 모드(Flash 모델 등)를 적용합니다. 실시간 대화나 빠른 반응이 필요한 앱에서 체감 속도를 크게 향상시킵니다.
저지연 / 고속
🎥 Analyze video content
업로드한 동영상의 내용을 AI가 분석합니다. 장면 인식, 핵심 요약, 자막 생성, 특정 장면 검색 등의 기능을 앱에 추가할 수 있습니다.
영상 분석
📝 Transcribe audio
오디오 파일이나 음성을 텍스트로 변환(STT/음성 인식)하는 기능을 앱에 넣습니다. 회의 녹음 전사, 인터뷰 기록 등에 활용 가능합니다.
STT / 음성 인식
