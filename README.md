# 🏛️ 사랑의교회 여직장인 순장반: Google AI Studio 바이브 코딩

설치 없이 브라우저로 끝내는 **스마트 케어노트 제작 및 일터 자립 가이드** 강의 자료 저장소입니다.

---

## 📂 주요 구성 파일

| 파일/디렉토리 | 설명 |
| :--- | :--- |
| **`student.html`** | **[수강생용]** AI Studio 10단계 화면 가이드(Lightbox 이미지 뷰어) 및 Step 1~4 단계별 프롬프트 실습 페이지 |
| **`index.html`** | **[강사용]** 150분 완성 통합 강의 지도안 (타임테이블, 실패 방지 체크포인트, 트러블슈팅 매뉴얼) |
| **`화면설명/`** | Google AI Studio 화면 가이드용 고화질 캡처 이미지 10장 |
| **`kakao_notifier/`** | 순원 알림 및 케어노트 연동 백엔드/프론트엔드 프로젝트 |
| **`text/`** | 순모임 스마트 케어노트 React/Vite 실습 프로젝트 소스 |

---

## 🚀 빠른 시작 (수강생 & 강사)

본 강의 자료는 별도의 웹 서버나 복잡한 설치 없이 **구글 크롬(Chrome) 브라우저**에서 HTML 파일을 직접 열어 즉시 활용하실 수 있습니다.

1. **수강생 실습 페이지 열기**:
   - `student.html` 파일을 더블 클릭하여 크롬 브라우저로 엽니다.
   - **탭 1**: `🖥️ 1. AI Studio 화면 설명 가이드`를 통해 10장의 화면 구성을 먼저 눈으로 익힙니다. (클릭 시 1.5배 확대 및 드래그 지원)
   - **탭 2**: `🚀 2. 실습 & 프롬프트`에서 단계별 원클릭 복사 버튼을 눌러 AI Studio에 붙여넣습니다.

2. **강사용 지도안 열기**:
   - `index.html` 파일을 열어 150분 타임테이블과 필수 점검 사항을 확인합니다.
