🎯 1. 강의 개요 및 학습 목표

평일 직장 업무와 주말 소그룹(다락방) 사역을 감당하느라 늘 에너지가 부족한 여직장인 순장들을 위해, 복잡한 개발 도구 설치 없이 브라우저 대화창만으로 실제 작동하는 웹앱을 만들어내는 바이브 코딩(Vibe Coding) 실습형 워크숍입니다.

1. 사역 시간의 극적 단축 (시간 청지기)

수작업 출석부와 흩어진 카톡 기도제목을 간편하게 취합·공유하는 맞춤형 웹앱을 완성합니다.

2. 설치 0초 바이브 코딩 체득

터미널이나 에디터 없이, 브라우저 대화창에 우리말로 지시하고 실시간 Preview로 확인하는 최신 AI 개발 경험을 얻습니다.

3. 일터 실무 생산성 확장

다락방 도구를 단어 몇 개만 바꿔 '팀 주간 업무 To-Do 취합 대시보드'로 즉시 변형하여 내일 회사에서 바로 써먹습니다.

📋 2. 사전 준비, OS 호환성 & 보안 수칙

수강생 준비물 & OS 주의사항

  • 개인 노트북 & 충전기 (Windows / Mac 무관)
  • 마우스 지참 필수 권장 (우측 스마트폰 화면 조작용)
  • Google Chrome 브라우저 필수 (Mac 사용자도 Safari 대신 반드시 Chrome 사용)
  • 개인 구글(Gmail) 계정 필수 (회사 구글 Workspace 계정은 관리자 보안 차단 빈번)

강사용 체크리스트

  • 교육장 Wi-Fi 접속 안정성 & 강사 핫스팟 비상망 대기
  • 비상용 구글 계정 2~3개 준비 (로그인 막힌 수강생 대여용)
  • 강사 빔 화면 배율 100~110% 유지 (창 가려짐 방지)
  • 본 안내 웹페이지 링크를 단축 URL로 칠판에 적어두기
  • 강사용 Step 3 완성 프로젝트 Share 링크 사전 준비
💡 회사 계정 로그인 충돌 해결법 (현장 필수 안내):
직장인 수강생의 노트북 크롬에 회사 구글 계정이 로그인되어 있어 AI Studio 접속이 차단(403 Error)되는 경우, 즉시 Ctrl + Shift + N (Mac: Cmd + Shift + N)을 눌러 새 시크릿 창을 띄운 뒤 개인 Gmail로 로그인하도록 지도하세요.
🚨 필수 개인정보 보호 수칙 (강사 오프닝 엄격 공지):
Google AI Studio 무료 티어 약관상, 실제 순원의 실명, 연락처, 내밀한 가정사나 질병 기도제목은 절대 입력하지 마시고, 반드시 가상의 이름(은지, 수진 등)과 가상 기도제목으로 실습합니다.

📷 스크린샷 첨부 위치 #1
Google AI Studio Build Mode 전체 화면 (Must & Skip 하이라이트)
좌측 프롬프트 입력창, 중앙/우측 Preview 화면, 우측 상단 Share 버튼에 초록 박스를 치고, Playground/Code 탭에는 붉은 X 표시를 한 캡처 이미지를 여기에 배치하세요.

⭕ 실습 중 꼭 볼 3가지 (Must)

  • 우측 실시간 화면 (Preview): 내가 만든 앱이 실제로 구동되는 스마트폰 화면. 마우스로 버튼 누르고 직접 테스트.
  • 좌측 하단 입력창 (Prompt Bar): "살을 붙이고 수정 지시를 내리는 창구". 우리말로 지시 입력.
  • 우측 상단 [Share] 버튼: 다 만든 후 내 스마트폰으로 앱 링크를 보낼 때 누르는 관문.
  • (참고) 좌측 메뉴 + New app은 4부 자립 실습 때 딱 한 번만 누릅니다.

❌ 건너뛸 영역 3가지 (Skip)

  • Preview 상단의 <> (Code 보기 탭): 누르면 복잡한 개발 코드가 쏟아집니다. 누르지 마세요.
  • 좌측 메뉴의 Playground & Dashboard: API Key 및 결제 관련 개발자 영역. 쳐다보지 마세요.
  • 좌측 채팅에 뜨는 파일 이름들 (app/src/...): AI가 혼자 일했다는 영수증일 뿐이니 무시.

💻 5. 실습용 프롬프트 템플릿 (Step 1 ~ Step 4 + 보너스 Step 5)

수강생 교안(`student.html`)과 100% 동일한 순서로 구성되어 있습니다.

Step 1 (필수) 기본 뼈대 앱 빌드 (18분)
모바일 브라우저와 PC에서 바로 편리하게 사용할 수 있는 '다락방 스마트 케어노트' 웹앱(Web app)을 만들어줘. [필수 요구사항] 1. 상단 헤더: 오늘 날짜 표시, '00다락방 케어노트' 제목 (클릭하여 직접 수정 가능) 2. 순원 목록 카드 리스트: - 순원 이름 - 모임 출석 체크박스 - 이번 주 나눔 및 기도제목 입력칸 (여러 줄 텍스트 입력 가능) - 각 순원 카드마다 [삭제] 버튼 3. 하단 컨트롤: 새로운 순원을 추가할 수 있는 [새 순원 추가] 버튼 4. 테스트용 가상 순원 2명(은지, 수진)의 데이터를 기본값으로 화면에 미리 채워줘. 5. 모바일 스마트폰 화면 폭에서도 카드가 깔끔하게 보이도록 반응형 카드 UI로 구성해줘. 외부 백엔드 서버나 로그인 없이 브라우저에서 바로 동작하는 구조로 만들어줘. 완성 후 오른쪽 Preview 화면에서 바로 마우스로 버튼을 누르고 테스트할 수 있게 즉시 실행해줘.

Step 2 (필수) 새로고침해도 유지되는 브라우저 저장 연동 (16분)
현재 프로젝트의 기존 순원 목록, 순원 추가/삭제, 출석 체크박스, 기도제목 입력 UI와 기능을 100% 그대로 유지해줘. 이번 단계에서는 [데이터 자동 저장 기능]만 정확히 추가해줘. 1. 사용자가 순원을 추가/삭제하거나, 출석 체크박스를 누르거나, 기도제목을 입력할 때마다 별도의 서버 없이 브라우저 자체 로컬 저장소(localStorage)에 모든 데이터가 실시간으로 자동 저장되게 해줘. 2. 사용자가 브라우저를 새로고침하거나 창을 닫았다가 다시 열었을 때, 마지막에 저장된 순원 목록과 입력 내용이 그대로 다시 화면에 복원되어 표시되게 해줘. 3. 기존 레이아웃 스타일과 컴포넌트 구조는 임의로 바꾸지 마. 기존 기능을 손상시키지 말고 오직 브라우저 로컬 저장 연동 로직만 안전하게 적용해줘.
💡 강사 티칭 팁 (localStorage 올바른 설명):
수강생에게 기술 용어를 쓰지 마세요. "스마트폰 메모장에 쓴 글이 남아있는 것처럼, 브라우저 안에 **'내 브라우저 안의 개인 서랍장'**을 하나 달아주는 겁니다. 단, 이 서랍장은 이 컴퓨터 브라우저 안에만 있으므로 다른 컴퓨터나 스마트폰으로 자동으로 따라가지는 않습니다"라고 한계를 명확히 짚어줍니다.

현재 프로젝트의 모든 순원 데이터 관리, UI 레이아웃, 브라우저 로컬 자동 저장 로직을 100% 보존해줘. 이번 단계에서는 화면 하단에 [카카오톡용 문구 자동 생성 및 복사 기능]만 추가해줘. 1. 화면 하단에 '카카오톡 공유 미리보기' 영역을 만들고, 그 안에 읽기 전용 텍스트 상자(readonly textarea)를 항상 눈에 보이게 배치해줘. - 오늘 날짜, 총 출석 인원 및 명단, 순원별 나눔/기도제목이 정돈된 줄바꿈 포맷(이모지 포함)으로 실시간 자동 조합되어 표시되어야 해. 2. 텍스트 상자 바로 위에 눈에 띄는 색상의 [카톡 문구 복사하기] 버튼을 만들어줘. - 버튼을 클릭하면 navigator.clipboard.writeText를 사용하여 카톡 양식 전문이 클립보드에 자동 복사되고 "복사 완료! 카톡에 붙여넣으세요"라는 토스트 알림을 띄워줘. - 만약 브라우저 보안 제약이나 모바일 환경으로 인해 자동 복사가 차단되더라도 에러로 멈추지 말고, 하단 텍스트 상자의 내용이 자동으로 전체 선택(select)되도록 처리한 뒤 "PC에서는 Ctrl+C(Mac: Cmd+C), 스마트폰에서는 길게 눌러 복사하세요"라고 안내해줘. 3. 기존 순원 추가/삭제 및 저장 기능은 절대 건드리지 마.
🎓 공식 수료 기준: [카톡 문구 복사하기] 누르고, PC 카톡 '나와의 채팅방'에 Ctrl + V (Mac: Cmd + V) 했을 때 보고서가 붙여넣어지면 오늘 워크숍 공식 수료입니다!

🚀 7. 수강생 자립을 위한 3대 핵심 장치

수강생이 워크숍 후 집에 가서도 혼자 힘으로 아이디어를 앱으로 만들 수 있도록 연결해 주는 교육 설계 브릿지입니다.

• 순원 이름 ➔ 거래처명 (또는 팀원 이름, 우리 아이 이름)
• 출석 체크 ➔ 입금 확인 (또는 주간 업무 완료, 오늘 칭찬 스티커)
• 기도제목 ➔ 미수금 메모 (또는 주간 핵심 이슈, 칭찬 한마디)

장치 2: 집에 가서 혼자 쓰는 '3문장 만능 공식'

복잡한 프롬프트는 잊어도 이 3문장 뼈대만 기억하면 어떤 웹앱이든 백지에서 시작할 수 있습니다.

[1문장 - 뭐 만들지?] : 모바일에서 쓰는 깔끔한 '[ OO 관리 ]' 웹앱 만들어줘.
[2문장 - 뭐 들어가지?] : 화면에 [ A, B, C ]를 보여주고, 버튼을 누르면 [ D ]가 되게 해줘.
[3문장 - 실행해줘] : 서버 없이 브라우저에서 바로 동작하게 오른쪽 화면에 실행해줘.

장치 3: AI와 대화하며 말로 고치는 법 (Vibe 코딩의 본질)

첫 프롬프트로 완벽하게 만들려 하지 말고, 나온 화면을 보며 카카오톡 하듯이 "글자 크기 좀 키워줘", "버튼 색깔 핑크색으로 바꿔줘", "체크하면 줄 그어지게 해줘"라고 한 줄씩 대화로 다듬어가는 경험을 심어줍니다.

🎁 보너스 장치: AI에게 기획을 시키는 '역질문 기획 치트키'

수강생 교안 하단에 접이식(아코디언)으로 숨김 처리되어 있습니다. 수강생이 "아이디어는 있는데 어떻게 기획해야 할지 막막해요"라고 질문하거나 시간 여유가 있을 때 활용하세요.

💡 핵심 지도 멘트: "순장님들, 기획서 쓰려고 머리 싸매지 마세요! AI한테 '나 이거 만들고 싶은데, 네가 수석 기획자가 되어서 필요한 기능 3개 추천해주고, 나한테 결정할 질문 3개만 물어봐줘'라고 던지시면 AI가 알아서 기획 인터뷰를 진행해 줍니다. 질문에 답만 하시면 기획이 끝납니다!"

현장 돌발상황 즉각 해결법 (Troubleshooting):
