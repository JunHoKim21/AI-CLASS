# 💬 카카오톡 순원 말씀/공지 자동 발송기

순모임, 청년부, 소그룹 순원들에게 매번 반복되던 1:1 말씀/공지 카톡 전송을 단 한 번의 클릭으로 자동화하는 프로그램입니다.

---

## 🚀 빠른 시작 방법

1. PC 카카오톡이 로그인되어 있는지 확인합니다.
2. 폴더 내 **`시작하기.bat`** 파일을 더블클릭합니다.
3. 프로그램 창이 열리면:
   * 수신자(순원)를 확인 및 선택합니다.
   * 필요 시 **`[🖼️ 사진 첨부]`** 버튼으로 포스터/주보 이미지를 첨부합니다.
   * 말씀 본문을 복사-붙여넣기합니다. (본문에 `{이름}`을 넣으면 순원 이름으로 자동 치환됩니다)
   * **`[▶ 전송 시작]`** 버튼을 누릅니다.

---

## 📌 주요 기능 안내

### 1. 엑셀/메모장 명단 일괄 등록
* **`[📋 엑셀/명단 일괄 등록]`** 버튼을 누릅니다.
* 엑셀에서 순원 이름들을 복사(`Ctrl+C`)하여 붙여넣기(`Ctrl+V`)하면 줄바꿈/쉼표를 자동 인식하여 한 번에 등록됩니다.
* 한 번 등록된 명단은 `contacts.json`에 영구 보관되므로 프로그램을 껐다 켜도 유지됩니다.

### 2. 사진 + 말씀 연속 발송
* 사진을 첨부하면 **사진이 먼저 대화방에 전송된 후, 1초 뒤 말씀 본문이 순서대로 자동 발송**됩니다.
* 사진만 보내거나, 글만 보내는 것도 가능합니다.

### 3. 초고속 전송 모드
* 1명당 약 **1.5초 ~ 2초** 만에 사진과 글이 전송됩니다.
* 10명 발송 시 약 15~18초, 100명 발송 시 약 2분 내외로 전원 발송이 완료됩니다.

---

## ⚠️ 전송 중 주의사항

1. **마우스/키보드 조작 금지**: 전송이 진행되는 동안에는 컴퓨터가 카톡 창을 제어하므로 마우스나 키보드를 건드리지 마세요.
2. **긴급 중단**: 잘못 보낸 것을 발견하셨다면 **`[■ 중단]`** 버튼을 누르면 즉시 멈춥니다.
3. **카톡 친구 이름 일치**: 카카오톡에 저장된 친구 프로필 이름과 프로그램에 등록된 이름이 정확히 일치해야 대화방이 열립니다.
