# 💬 카카오톡 순원 말씀/공지 자동 발송기 (KakaoNotifier v2.0)

> **"매주 반복되던 1:1 순원 카톡 말씀·공지·주보 전송, 이제 단 한 번의 클릭으로 끝내세요!"**  
> 별도의 개발 도구(Node.js, Python 등) 설치 없이 **더블클릭만으로 즉시 실행되는 윈도우 전용 데스크톱 프로그램**입니다.

---

## ⚡ 초간단 실행 방법 (일반 사용자)

**Node.js나 Python 같은 프로그램 설치가 일절 필요 없습니다.**

1. **PC 카카오톡**을 켜고 로그인합니다. (창을 끄거나 최소화하지 말고 띄워두세요)
2. 다운로드받은 **`KakaoNotifier_배포용.zip`** 파일의 압축을 풉니다.
3. 폴더 안의 **`시작하기.bat`** (또는 `KakaoNotifier.exe`)를 더블클릭합니다.
4. 독립 데스크톱 프로그램 창이 열리면 바로 사용하실 수 있습니다!

---

## ✨ 핵심 기능

* **1:1 맞춤형 이름 치환 (`{이름}`)**:
  * 본문에 `{이름}`을 넣으면 각 순원의 이름으로 쏙 치환되어 정성 어린 1:1 메시지로 발송됩니다.
  * 예: `"안녕하세요 {이름} 순원님!"` ➔ `"안녕하세요 김준호 순원님!"`
* **사진 + 말씀 동시 발송**:
  * 주보, 공지 포스터, 성경 카드 사진을 첨부하면 사진과 글이 대화방에 함께 발송됩니다.
* **엑셀/카톡 명단 일괄 등록**:
  * `[명단 일괄 등록]` 버튼을 누르고 엑셀이나 카톡의 이름 명단을 복사해 붙여넣으면 1초 만에 전원 자동 등록됩니다.
* **스마트 검색 모드 분기**:
  * **👤 친구 목록에서 검색 (추천)**: 카톡 친구 탭에서 검색하여 1:1 대화방을 엽니다.
  * **💬 채팅방 목록에서 검색**: 이미 열려 있는 대화방이나 **'나와의 채팅'**으로 테스트할 때 사용합니다.
* **프로그램 내장 이용 가이드**:
  * 프로그램 우측 상단의 **`[이용 가이드]`** 버튼을 누르면 언제든지 상세 팁을 바로 확인하실 수 있습니다.

---

## ⚠️ 발송 중 주의사항

1. **전송 중 마우스/키보드 건드리지 않기**:
   * 발송이 시작되면 컴퓨터가 카톡 창을 열고 글을 입력합니다. 끝날 때까지 마우스나 키보드를 만지지 마세요.
2. **긴급 중단 가능**:
   * 발송 중 언제든지 화면의 빨간색 **`[전송 일시 중지]`** 버튼을 누르면 즉시 멈춥니다.
3. **친구 이름 일치 확인**:
   * 내 카카오톡에 저장된 친구 프로필 이름과 프로그램에 등록된 순원 이름이 정확히 일치해야 검색됩니다.

## 💻 개발자 안내 (소스 코드 직접 빌드 시)

일반 사용자는 빌드할 필요가 없으나, 소스를 직접 수정하고자 하는 개발자는 아래 절차를 참고하세요:

```bash
# 1. 프론트엔드 빌드 (Node.js 18+ 필요)
cd frontend
npm install
npm run build

# 2. 파이썬 환경 설정 및 실행 (Python 3.10+ 필요)
cd ..
pip install -r requirements.txt
python api_server.py
```
